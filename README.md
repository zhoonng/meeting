## 摘要

失智症是高齡化社會的重要公衛議題，發生風險可能跟飲食型態與生理狀態有關。色胺酸是一種必需胺基酸，跟神經保護、失智症預防可能有關，但目前證據多來自動物實驗，人類族群的證據還不夠。

本研究用國際公開的臨床與生活型態資料，做初步的描述性統計與分層分析，比較「高色胺酸飲食」與「低色胺酸飲食」的人，在不同生理風險（基因、睡眠品質、慢性發炎）下，失智症發生情形是否有差異。

本研究目的是初步檢視此研究架構在公開次級資料中的適用性，作為後續分析之參考基礎。未來擬在此基礎上，透過更詳細的資料庫內容，進一步加入多變項統計方法及機器學習實作，針對失智症的風險來透過不同因子進行更深入的分析及預測。

## 研究背景與動機

* **失智症的全球挑戰**：隨著全球高齡化社會來臨，失智症 (Dementia) 已成為當今公共衛生領域亟待解決的挑戰。根據 WHO 2021 年報告，全球有超過 5,500 萬名失智者，預計到 2050 年將成長至 1.39 億人。
* **發病機轉與生活型態的交互作用**
    - **血清素／褪黑激素路徑**：有助睡眠、抗發炎，可能有神經保護效果。
    - **犬尿酸路徑**：慢性發炎時活性上升，代謝物可能有神經毒性。
    - **先天因子**：帶有 **APOE ε4** 基因與失智風險增加有關。
    - **後天因子**：睡眠差、抽菸、飲酒、糖尿病、高血壓等，會誘發慢性發炎，讓色胺酸代謝偏向「有害」的犬尿酸路徑。
    - **飲食**：地中海飲食核心食材（豆類、魚、堅果、乳製品）富含高色胺酸及胺基酸代謝相關之營養素。
* **研究切入點**：由於現有研究多建立於動物實驗或特定研究族群之分析上，因此本研究想透過次級資料觀探討飲食方面的改善與失智症風險之關聯。

## 初步分析內容與發現

### 1. 基因風險分層 (APOE_ε4組)
沒有 APOE ε4 的人，高色胺酸飲食者失智比例較低；但有 APOE ε4 的人，飲食差異影響不明顯 → 先天基因風險可能蓋過飲食的保護效果。

![圖9、APOE_ε4組](APOE組.png)

### 2. 睡眠品質分層
生理風險低時，高色胺酸飲食失智比例較低；但風險越高，飲食的差異就越不明顯 → 慢性壓力可能削弱飲食的保護效果。

![圖10、睡眠品質組](睡眠品質組.png)

### 3. 慢性發炎程度與羅吉斯迴歸模型
模型顯示的趨勢跟預期相反——發炎程度越高，預測的失智症機率反而越低，而且兩種飲食型態在高發炎組的差異也變得不明顯 → 因發炎等級 3 的樣本數極少，可能造成樣本偏差與回歸模型在處理資料時的限制，因此後續需要透過更完整的模型與樣本，進行進一步驗證。

## 預期結果與未來展望

* **架構可行性驗證**：成功驗證「飲食型態 × 多重生理風險」分析架構於公開次級資料的可行性。
* **辨識關鍵因子**：找出哪些生理風險因子和飲食組合比較值得深入研究，作為未來變項篩選的依據。
* **釐清傳統模型限制**：發炎迴歸模型揭示了小樣本極端值造成的估計偏差，顯示傳統線性模型在處理複雜交互作用時的侷限。
* **導入機器學習預測**：以此實證為基礎進行特徵篩選，未來將更完整的資料庫導入機器學習，建立精準的失智症風險預測模型。
